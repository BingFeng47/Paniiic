# Kiroween 2026 submission checklist

Source: https://kiroween.devpost.com/ and its Official Rules. Re-read the official page before
submitting; this is our summary. Times are Singapore time (UTC+8).

## Dates

- [ ] Both team members registered on Devpost ("Join hackathon"), and joined as one team.
- [ ] Free Kiro credits (4,000 per person) requested before **2 Dec 04:00**, redeemed before 4 Dec PT.
- [ ] Submission draft opened early on Devpost and saved regularly.
- [ ] Submitted before **5 Dec 06:00** (4 Dec 14:00 PT). No extensions, no edits after.
- [ ] Live URL kept working through judging (until 30 Jan 2027).

## Eligibility

- [ ] Project built during the submission period (30 Oct – 4 Dec 2026).
- [ ] Any code that existed before this repo, apart from frameworks and libraries, declared in the
      submission. (The trial build was made 19 Nov 2026 without Kiro. Declare it if we copy code
      from it.)
- [ ] Category: **Costume Contest**.

## Repository

- [ ] Public **GitHub** repo (GitLab and Bitbucket are not accepted).
- [ ] OSI license (MIT) at the root and shown in the repo's About section.
- [ ] `/.kiro` at the root with specs, hooks and steering. **Not** in `.gitignore`.
- [ ] All source, assets and instructions needed to run the game. README has run steps.

## Submission form

- [ ] Live app URL (static build on GitHub Pages, Netlify or Vercel).
- [ ] Text description of features.
- [ ] Demo video under 3 minutes, public on YouTube, showing the game running on our machine.
      No copyrighted music, no third-party trademarks or logos.
- [ ] Demo video cuts the run to stay under 3 minutes. A winning run lasts about 3:00 to 3:20
      from dialing (median win about 196 s in the 24 Nov balance report), so cut at least the
      20 s dial-up.
- [ ] "How we used Kiro" writeup (run `/submission` to draft it from `docs/kiro-log.md`).
- [ ] All material in English.

## Bonus prizes we can enter

- [ ] Bonus Blog Prize: blog post on an external platform during the submission period, stating it
      was written for Kiroween 2026. Submit the URL.
- [ ] Social Blitz: a post starting with `#KiroweenHackathon26` about our favourite thing in Kiro
      and how it changed our workflow. Submit the URL.
- [ ] Best Demo: automatic for top-10% entries with the best Presentation score.
- Not eligible: Ghost of Kiroween Past (not in 2025). Student prize only if both of us are
  students. Startup prize only for startup founders.

## Judging (each 20%)

- [ ] Potential Impact: who it is for and why it matters (fun, nostalgia, spotting deceptive UI).
- [ ] Technological Implementation: deep, varied Kiro use, visible in `.kiro/` and the writeup.
- [ ] Design: feels like a finished product, not a tech demo.
- [ ] Innovation/Idea: the two-front dial-up zombie concept.
- [ ] Presentation: the video shows the full flow and is memorable.
